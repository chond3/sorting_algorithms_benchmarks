Compilation and Execution
1. Compile and Run the Main Program
gcc main.c ./algorithms/implementations/bubble.c ./algorithms/implementations/selection.c ./algorithms/implementations/insertion.c ./algorithms/implementations/merge.c ./algorithms/implementations/quick.c ./algorithms/implementations/heap.c ./algorithms/implementations/shell.c ./algorithms/implementations/radix.c ./list_management/implementations/generate_list.c ./list_management/implementations/copy_list.c ./benchmarks/implementations/benchmarks.c ./gnuplot_management/implementations/gnuplot.c ./gnuplot_management/implementations/plot.c -o main.exe


Run the program:

./main.exe

2. Compile and Run the Gnuplot Program
gcc gnu.c ./gnuplot_management/implementations/gnuplot.c ./gnuplot_management/implementations/plot.c -o plot.exe


Run the program:

./plot.exe
